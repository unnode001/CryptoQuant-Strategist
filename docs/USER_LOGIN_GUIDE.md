# 用户登录功能使用指南

## 功能概述

CryptoQuant-Strategist 现已集成完整的用户登录和数据同步功能。你可以：

- 📝 **注册账号**：使用邮箱创建账号
- 🔐 **安全登录**：密码加密存储
- ☁️ **云端同步**：所有数据自动同步到 Supabase
- 📱 **多设备访问**：在不同设备访问相同数据
- 🔄 **离线模式**：未登录时使用本地存储

## 界面说明

### 1. 用户信息栏

应用顶部显示用户状态：

#### 未登录状态
```
🔘 离线模式（数据仅保存在本地）  [登录 / 注册]
```
- 灰色指示灯：表示离线模式
- 数据保存在浏览器本地 localStorage
- 点击"登录 / 注册"按钮打开登录界面

#### 已登录状态
```
🟢 已登录: your@email.com  [退出登录]
```
- 绿色脉冲指示灯：表示在线状态
- 显示当前登录的邮箱
- 同步中会显示旋转图标
- 点击"退出登录"可登出

### 2. 登录/注册模态框

点击"登录 / 注册"按钮后，会弹出认证对话框：

#### 登录标签
- **邮箱**：输入注册时使用的邮箱
- **密码**：输入密码
- 点击"登录"按钮
- 切换到"注册"：点击底部"没有账号？点击注册"

#### 注册标签
- **邮箱**：输入有效邮箱地址
- **密码**：至少 6 个字符
- **确认密码**：重复输入密码
- 点击"注册"按钮
- 切换到"登录"：点击底部"已有账号？点击登录"

## 使用流程

### 首次使用（注册新账号）

1. **打开应用**
   - 访问应用 URL
   - 顶部显示"离线模式"

2. **注册账号**
   - 点击"登录 / 注册"按钮
   - 选择"注册"标签
   - 输入邮箱（例如：user@example.com）
   - 输入密码（至少 6 个字符）
   - 再次输入密码确认
   - 点击"注册"按钮

3. **自动登录**
   - 注册成功后自动登录
   - 顶部显示"已登录: user@example.com"
   - 本地数据会自动同步到云端

4. **开始使用**
   - 所有操作自动保存到云端
   - 策略、回测历史、配置等都会同步

### 老用户登录

1. **打开登录界面**
   - 点击"登录 / 注册"按钮
   - 确保在"登录"标签

2. **输入凭证**
   - 输入注册的邮箱
   - 输入密码
   - 点击"登录"按钮

3. **数据加载**
   - 登录成功后从云端加载数据
   - 之前保存的策略、回测历史等会自动恢复

### 退出登录

1. 点击顶部的"退出登录"按钮
2. 应用切换到离线模式
3. 数据仍保存在本地（不会丢失）
4. 下次登录时会同步到云端

## 数据同步说明

### 同步的数据

以下数据会自动同步到云端：

- ✅ **LLM API 配置**（OpenAI、Anthropic等）
- ✅ **交易所 API 配置**（Binance、Coinbase等）
- ✅ **市场数据源**
- ✅ **回测历史记录**
- ✅ **用户配置**（语言、侧边栏状态等）

### 同步时机

- 📤 **创建数据**：立即同步到云端
- ✏️ **修改数据**：修改后立即同步
- 🗑️ **删除数据**：删除后立即同步
- 📥 **登录时**：从云端加载所有数据

### 离线模式

未登录时：
- 数据仅保存在浏览器 localStorage
- 功能完全可用
- 清除浏览器数据会导致数据丢失
- 登录后，本地数据会合并到云端

## 常见问题

### Q1: 忘记密码怎么办？
A: 目前版本暂不支持密码重置，请联系管理员或重新注册。（密码重置功能即将推出）

### Q2: 数据会丢失吗？
A: 登录状态下，数据保存在云端，非常安全。离线模式下，数据保存在浏览器本地，清除浏览器数据可能导致丢失。

### Q3: 可以在多个设备使用吗？
A: 可以！登录同一账号，数据自动同步。

### Q4: 同步失败怎么办？
A: 检查网络连接和 Supabase 配置。错误信息会在浏览器控制台显示。

### Q5: 离线模式和登录模式有什么区别？
A:
- **离线模式**：数据只在本地，清除浏览器数据会丢失
- **登录模式**：数据云端备份，多设备同步

### Q6: 注册需要邮箱验证吗？
A: 默认不需要，注册后立即可用。管理员可在 Supabase 后台开启邮箱验证。

### Q7: 密码要求是什么？
A: 至少 6 个字符。建议使用强密码（字母+数字+符号）。

### Q8: 可以修改邮箱吗？
A: 目前版本不支持修改邮箱，需要重新注册。

## 安全提示

⚠️ **重要安全建议**：

1. **使用强密码**
   - 至少 8 个字符
   - 包含大小写字母、数字和符号
   - 不要使用常见密码

2. **不要分享账号**
   - 每个用户应有独立账号
   - API 密钥等敏感信息会被存储

3. **定期更换密码**
   - 建议每 3-6 个月更换一次
   - 怀疑泄露立即更换

4. **注意使用环境**
   - 公共电脑记得退出登录
   - 不要在不安全的网络环境输入密码

## 技术细节

### 认证流程
1. 用户输入邮箱和密码
2. Supabase Auth 验证凭证
3. 返回 JWT Token
4. Token 自动存储在浏览器
5. 后续请求自动携带 Token

### 数据保护
- 密码使用 bcrypt 哈希存储
- 传输使用 HTTPS 加密
- Row Level Security (RLS) 保护数据
- 用户只能访问自己的数据

### Session 管理
- Session 自动续期
- 30 天内保持登录
- 关闭浏览器不会登出
- 手动登出立即失效
